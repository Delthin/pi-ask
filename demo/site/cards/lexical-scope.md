# 词法作用域

> 预设演示内容，不来自用户会话。

词法作用域指变量的可访问范围由代码书写位置决定，而不是由函数被调用的位置决定。函数定义在哪个作用域里，就把那个作用域作为自己的外层环境。

查找变量时，引擎先看当前作用域，找不到再沿外层作用域逐级向上，直到全局作用域。这条查找链在函数定义时已经固定。

```js
const name = "外层";

function show() {
  console.log(name);
}

function run() {
  const name = "调用处";
  show();
}

run(); // 外层
```

`show` 定义在全局作用域，外层环境就是全局作用域。它在 `run` 里被调用时不会改用 `run` 的局部变量，所以打印的是外层的值。

词法作用域让函数依赖哪些变量可以从书写位置读出来，也让闭包拥有确定的环境。

### 示例回答（预设） · 2024-01-01T09:01:30.000Z

在函数定义时确定。函数记录自己书写位置所处的作用域作为外层环境，调用时按这条链查找变量，与调用位置无关。
