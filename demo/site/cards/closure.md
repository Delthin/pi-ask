### 闭包

#### 知识整理

闭包是函数和它定义时所处词法环境的组合。外层函数返回后，返回的函数仍然引用外层变量，这些变量因此继续存在，可以读取和修改。

下面的计数器把 `count` 留在 `makeCounter` 的作用域里，返回的函数每次调用都操作同一个 `count`：

```js
function makeCounter() {
  let count = 0;
  return () => ++count;
}

const next = makeCounter();
console.log(next()); // 1
console.log(next()); // 2
```

`makeCounter()` 调用结束后，`count` 没有随调用结束而消失，因为返回的箭头函数持有对它的引用。每次调用 `next` 读到的是同一个 `count`，状态因此延续。

闭包常用来保存私有状态，也用来让回调记住定义时的参数。变量的生命周期由是否仍被引用决定，函数调用是否结束不直接决定它。

### 闭包读取的是变量，不是创建时的快照

#### 知识整理

闭包保留对词法环境中变量的访问。外层代码修改同一个变量后，闭包再次读取时会得到修改后的值：

```js
let count = 0;
const read = () => count;
count = 2;
console.log(read()); // 2
```

如果另一个变量保存了预先计算好的结果，读取的仍然是那个结果；它不会因为原变量改变而自动重新计算。这次补充解释变量捕获，上次记录中的闭包定义和计数器示例仍然适用。

### 示例回答（预设） · 2024-01-03T08:58:30.000Z

闭包读取的是对应词法环境中的变量。同一个变量被修改后，后续读取会得到新值；已经保存在其他变量里的计算结果不会因此自动更新。
