### 用户问题（user） · 2024-01-01T09:00:00.000Z

为什么说闭包会让变量“活得比函数调用更久”？

<a id="message-1"></a>

### 示例回答（预设） · 2024-01-01T09:00:30.000Z

函数返回后，它的调用帧会退出。闭包让函数继续访问定义时的词法环境，返回的函数仍能读取和修改其中的外层变量。被闭包引用的对象能否回收，要看它们是否还从根对象可达。

<a id="message-2"></a>

### 用户问题（user） · 2024-01-01T09:01:00.000Z

词法作用域是在什么时候确定的？

<a id="message-3"></a>

### 示例回答（预设） · 2024-01-01T09:01:30.000Z

在函数定义时确定。函数记录自己书写位置所处的作用域作为外层环境，调用时按这条链查找变量，与调用位置无关。

### 用户问题（user） · 2024-01-01T09:02:00.000Z

闭包占用的内存什么时候能被回收？

<a id="message-5"></a>

### 示例回答（预设） · 2024-01-01T09:02:30.000Z

当相关对象不再从根对象可达时，就可以被回收。一个仍然可达的闭包可能通过词法环境保留外层对象；移除这条引用以及其他引用后，对象就不再可达。实际回收时机由引擎决定。

### 用户问题（user） · 2024-01-01T09:03:00.000Z

Promise 的 then 回调为什么能用到外面的变量？

<a id="message-7"></a>

### 示例回答（预设） · 2024-01-01T09:03:30.000Z

回调和普通函数一样携带定义时的词法环境。then 注册的回调在微任务中执行，作用域链仍然指向书写位置，因此能读到外层变量。
